# 阅读方式

每个模块都是同一条攻击链在**不同限制**下的变形。

一个场景里通常有：

1. **场景回顾** — 失败点
2. **前提与假设** — 已经具备的条件
3. **准备（攻击机侧）** — Kali 上要备好的东西
4. **执行步骤** — 编号步骤
5. **Lab files** — 该步用到的完整实验文件
6. **验证** — 怎样算成功
7. **失败分支** — 下一条路
8. **考试注意 / OPSEC** — 时间和痕迹

先做无害回调，再上真实载荷。x86 / x64 不要混。分阶段载荷的每一段必须走**同一条**已验证路径（地址、端口、协议、代理）。
