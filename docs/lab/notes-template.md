## 报告结构（通用渗透测试）

1. 执行摘要：目标是否达成、关键路径一张图
2. 范围与授权：时间窗、系统清单、明确排除项
3. 按主机写攻击路径：初始访问 → 提权 → 横向，每步命令与证据
4. 发现项：描述 / 复现 / 影响 / 修复
5. 附录：命令清单、时间线、脱敏后的凭据

不要在公开仓库提交 `loot/` 或带真实客户主机名的笔记。
