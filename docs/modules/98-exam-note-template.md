# 98 · 考试记录与报告模板

> OSEP 要求提交渗透测试报告，评分也看过程可复现性。**边做边记**，不要事后补。
> 用法：每进入一个场景，复制一份「单场景记录模板」，粘到你的笔记里（Obsidian/Notion/纯文本都行）。

## 3. 报告结构建议（按 OSEP 常见要求）

```text
1. 执行摘要
   - 达成目标、时间线、关键权限提升路径（一句话一张图）
2. 测试范围与方法
   - 授权说明、目标清单、时间窗
3. 攻击路径（按主机分章）
   - 主机 X：初始访问 → 权限提升 → 横向 → 证据
   - 每步：命令 + 输出截图/文本 + 为什么可行
4. 发现的问题（按严重度）
   - 问题描述 / 复现步骤 / 证据 / 影响 / 修复建议
5. 附录
   - 完整命令清单、脚本清单、凭据与哈希（脱敏后）、时间线
```

---

## 4. 记录时容易漏的东西

- [ ] 每条命令的**完整输出**（不要只记"成功了"）
- [ ] 时间戳（报告时间线要用）
- [ ] 位数与系统版本（决定载荷形态）
- [ ] 失败的尝试（评审会看你怎么排查）
- [ ] 凭据来源（从哪台机器、哪个文件、哪次转储拿到）
- [ ] 会话的初始进程与用户（后续迁移要对照）
