# 使用边界

这些笔记只用于：

- 你拥有或已获得**书面授权**的系统
- OffSec 等厂商提供的**官方实验 / 考试环境**（按对方协议使用）
- 你自己搭的隔离实验室

未授权扫描、入侵、投递载荷，在多数法域都是违法的。免责声明不能把未授权行为变成合法。

## 源码怎么用

页里的 VBA / HTA / C# / PowerShell / ASPX **是学习用骨架**：自己改 `LHOST`，在隔离 lab 或官方考试环境编译、验证。

GitHub 上大量同类 dual-use 研究代码。本站按同样方式公开**源码文本**，并标明用途。

| 放 | 不放 |
|---|---|
| 带占位符的源码和命令 | 编译好的 `.exe` / `.dll` / 二进制 Release |
| 公开工具（Impacket、msfvenom）的用法 | 付费课程 PDF、靶场主机名、逐步通关答案 |
| 指向他人仓库的链接 | 整站镜像别人的 cheat sheet |

需要完整代码时，请在**自己的实验机**上根据公开工具文档自行编写和编译，不要从本站下载现成马。

## 和 OffSec 的关系

本站**不是** OffSec 教材摘要，也不是考试题解。

OSEP / PEN-300 是 OffSec 的商标与课程。这里只整理公开的 Windows / AD / Linux 进攻性安全**概念**和**公开工具**用法。课程正文、实验拓扑、考试内容以 OffSec 平台为准。

## 命令怎么用

文中的命令是**模板**：

```text
LHOST    你的实验攻击机地址
LPORT    监听端口
TARGET   授权目标
DOMAIN   实验域名
USER / PASS / NTHASH   你在实验中已经合法取得的凭据
```

把它们换成真实生产网地址，或对未授权系统使用，是你自己的责任。

## 平台与法律

GitHub 允许 dual-use 安全研究内容，前提是不当作恶意软件 CDN、不当作正在进行的攻击基础设施。Cloudflare 等其它主机对「可下载恶意代码」更严。

人在中国时，还要面对《刑法》第 285 条第 3 款和《网络安全法》第 27 条：向不特定公众提供专门用于侵入、非法控制计算机信息系统的程序、工具，可能构成违法甚至犯罪。这是本站不托管现成 payload 的主要原因。
